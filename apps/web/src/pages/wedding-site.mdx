# Wedding site

![Wedding site](/projects/wedding-site-2026.webp)

## Overview

Wedding site is a guest-facing site for sharing wedding details. It covers schedule, sign-up and other practical information, plus a photo album so guests can follow along before and after the day.

The point was a warm, clear information hub rather than a generic template dump — everything a guest needs without hunting through group chats.

## Key Features

- Schedule and practical wedding information
- Guest sign-up flow
- Photo album for shared memories
- Real-time backend for dynamic content
- Media storage via R2
