# TUI portfolio

![TUI portfolio](/projects/tui-portfolio-2026.webp)

## Overview

TUI portfolio is the terminal twin of this portfolio site. Instead of opening a browser, you can SSH into `terminal.janharkonen.fi` and browse the same kind of profile, projects and contact information in an interactive terminal UI.

I wanted a playful but practical second surface for the portfolio — something that feels native in a terminal and still represents the same personal brand.

## Key Features

- SSH-accessible terminal portfolio experience
- Interactive navigation for profile and projects
- Shared content mindset with the web portfolio
- Deployed on a small VPS footprint
