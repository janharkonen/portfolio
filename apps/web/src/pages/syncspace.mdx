# SyncSpace

![SyncSpace](/projects/syncspace-2025.webp)

## Overview

SyncSpace is a simple list-and-checkbox tool for collaborative task management with real-time synchronization. The idea was deliberately minimal: shared lists, checkboxes, and updates that appear for everyone without ceremony.

It was a good sandbox for real-time collaboration patterns without overbuilding a full project-management suite.

## Key Features

- Shared task lists with checkboxes
- Real-time sync across collaborators
- Authenticated access
- Lightweight web UI
