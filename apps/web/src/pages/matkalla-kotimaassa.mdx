# matkalla.kotimaassa.fi

![matkalla.kotimaassa.fi](/projects/kotimaassa-fi-2025-2026.webp)

## Overview

matkalla.kotimaassa.fi is an AI-powered search engine for Finnish travel destinations. Users can explore destinations with customizable filters and sorting, backed by a RAG pipeline that grounds answers in destination content rather than generic chatbot fluff.

The goal was a practical travel discovery experience: find places that match what you care about, then dig into details without losing the filter context.

## Key Features

- Destination search with customizable filters and sorting
- RAG-based answers grounded in destination data
- Authenticated user flows where needed
- Full-stack TypeScript front end with a Python-backed pipeline
