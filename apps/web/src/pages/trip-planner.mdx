# Trip planner

![Trip planner](/projects/trip-planner-2025.webp)

## Overview

Trip planner is a website for the travel details of a 3-day trip for about 60 people. It gathers the timetable, relevant links and FAQ into one place so organizers and participants are not chasing information across messages.

I built it as a focused event microsite: clear schedule, practical links, and answers to the questions everyone asks repeatedly.

## Key Features

- Shared timetable for a multi-day trip
- Relevant links in one place
- FAQ for common participant questions
- Real-time content updates when plans change
