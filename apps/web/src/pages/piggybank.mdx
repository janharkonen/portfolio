# Piggybank

![Piggybank](/projects/piggybank-2025.webp)

## Overview

Piggybank is a personal finance tracker. It is meant for keeping an eye on money in and money out without turning into a full accounting suite — a practical dashboard for personal spending awareness.

I used it as a place to combine a Next.js front end with Convex and a Go/Postgres side for structured financial data.

## Key Features

- Track personal income and expenses
- Simple overview of financial activity
- Persistent storage in Postgres
- Hybrid stack with Convex and Go services
