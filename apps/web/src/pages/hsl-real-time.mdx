# HSL real time

![HSL real time](/projects/hsl-real-time-2026.webp)

## Overview

HSL real time shows live vehicle locations for Helsinki public transport. It is a focused map-oriented front end that pulls real-time transit data and keeps vehicles moving on the map as positions update.

I wanted a small, useful Helsinki-local tool that makes the transit network feel visible instead of abstract.

## Key Features

- Live vehicle positions on a map
- Focused Helsinki public transport view
- Lightweight React front end
- Simple deployment footprint
