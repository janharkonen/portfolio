# cdx

![cdx](/projects/cdx-2025.webp)

## Overview

cdx is yet again a tool I made to make my life easier. It is a fast and intuitive directory navigation tool for Linux that lets you quickly cd into directories using fuzzy search.

Basically I encountered countless times that I needed to cd into a directory, but I couldn't remember the exact name let alone the exact path. Usually I would just cd into the home directory and then use ls again and again to find the exact directory I needed. The amount of time this saves is astronomical.
