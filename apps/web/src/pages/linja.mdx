# LINJA

![LINJA](/projects/linja-2026.webp)

## Overview

LINJA is an AI-powered tool for managing live music events. It brings together artist, event and venue management as well as ticket sales in one place — the kind of operational surface a live-music team actually needs day to day.

I built it as a modern full-stack app with real-time data, auth, email, and payments wired in from the start, so the product could grow from admin tooling toward a complete event workflow.

## Key Features

- Artist, event and venue management in one app
- Ticket sales integrated into the event workflow
- Authentication and transactional email
- Payments via Stripe
- Real-time backend powered by Convex
